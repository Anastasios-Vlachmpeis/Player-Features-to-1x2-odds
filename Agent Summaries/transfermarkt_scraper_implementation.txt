Transfermarkt Scraper — Implementation Notes
============================================
(Layer 1: player ability baseline for the Greek Super League 1 prediction model)

WHAT WE BUILT IN THIS SESSION
-----------------------------
A requests + BeautifulSoup scraper that collects the ability baseline for every
player currently registered in Greek Super League 1 squads, and stores it in a
SQLite database (player_stats.db). No Selenium, no external APIs.


FILES
-----
1. db.py        (EXTENDED — existing odds functions left untouched)
   - Added PLAYER_DB_PATH -> player_stats.db
   - init_player_db()           : creates tm_players and tm_injuries tables
   - upsert_player(dict)        : INSERT ... ON CONFLICT(tm_id) DO UPDATE
                                  (re-running updates rather than duplicating)
   - upsert_injuries(tm_id,list): delete-then-insert per player, idempotent re-runs

2. tm_scraper.py (NEW — all scraping logic)
   - Shared requests.Session with a realistic Chrome User-Agent + headers
     (TM blocks the default requests UA).
   - _get(url): polite 2-3 second random delay between requests, 3 retries with
     backoff, early exit on 403/404.
   - get_clubs()                  : parses the league startseite page -> all clubs
     (entry point: super-league/startseite/wettbewerb/GR1)
   - get_squad(club_id,slug,name) : parses /kader/verein/{id} squad table
   - get_player_profile(tm_id,slug): parses /profil/spieler/{id}
   - get_player_injuries(tm_id,slug): parses /verletzungen/spieler/{id}

3. scrape_transfermarkt.py (NEW — entry point)
   - Run with: python scrape_transfermarkt.py
   - Flow: init DB -> get clubs -> for each club get squad -> for each player
     enrich with profile + injuries -> upsert all.
   - Console logging: club name, player count per club, saved count, failures.
   - A failed player is logged and skipped; the run does not crash.


DATA COLLECTED
--------------
tm_players : tm_id (canonical ID), full_name, dob, age, nationality,
             primary_position, secondary_position, market_value_eur,
             club, shirt_number, scraped_at
tm_injuries: tm_id, injury_type, date_from, date_to, matches_missed, scraped_at


FRAGILE SELECTORS (likely to break if TM changes layout)
--------------------------------------------------------
- Clubs table:        td.hauptlink a[href*='/startseite/verein/']
- Shirt number:       div.rn_nummer
- DOB:                detected by date regex across all <td>s (no fixed column)
- Market value:       td.rechts.hauptlink a
- Profile positions:  div.info-table span  +  table.auflistung td (layout fallback)
- Injury columns:     parsed by index (1,2,3,5), guarded by len(cells) < 6 check
