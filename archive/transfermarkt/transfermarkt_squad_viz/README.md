# Super League Squad Graph

Interactive 2D force-directed graph of Greek Super League squads: 14 team clusters with player nodes sized by market value. Click a team or player to inspect details in the side panel.

## Prerequisites

- Python 3.12+ with `player_stats.db` populated (run `python scrape_transfermarkt.py` first)
- Node.js 18+

## Run

From the **repo root**:

```bash
# 1. Export SQLite → JSON (re-run after each scrape)
python graph_viz/build_graph.py

# 2. Start the frontend
cd graph_viz/frontend
npm install
npm run dev
```

Open the URL shown by Vite (typically `http://localhost:5173`).

## Build for deployment

```bash
cd graph_viz/frontend
npm run build
npm run preview
```

Static output is in `graph_viz/frontend/dist/`.

## Data files

| File | Description |
|------|-------------|
| `frontend/public/data/graph.json` | Nodes (teams + players) and membership links |
| `frontend/public/data/players.json` | Player detail + injury history keyed by `tm_id` |

Both are generated by `build_graph.py` from `tm_players` and `tm_injuries` in `player_stats.db`.

## Features

- Central **Super League** hub node links every team cluster for easier navigation
- Team filter dropdown and player/team search
- Click team → zoom to cluster + squad summary
- Click player → profile panel with injury history
- Hover spotlight and dimmed neighborhood when a node is selected
- Team-colored nodes with dark theme
